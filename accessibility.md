# Accessibility
Here are some accessibility guidelines and things to keep in mind when creating Innovation Challenges. Information that is relevant to you will be included, but check out the resources for more information.

## Table of Contents
- [Text](#text)
- [Heading Hierarchy](#heading-hierarchy)
- [Resources](#resources)

## Text
- Text should be 12pt or larger in documents, and 18pt or larger in slideshows, in a standard-looking sans-serif font. This allows for the greatest readability.
- Bold and italic text can be used for emphasis, but shouldn't be used for large amounts of text or without meaning.

## Heading Hierarchy
- The title should be the only text in the document that uses the title size or largest heading size.
- Heading size should follow a logical order, going from largest to smallest without skipping a size.
- For example: # Title, ## Sections, ### Subsections, #### Sub-Subsections. It should look like this:
# Title
## Section
### Subsection
#### Sub-Subsection
