# Final Submission

Teams should submit a complete solution that addresses the objectives described in the challenge.

The submission should clearly communicate:

- The problem being addressed
- The proposed solution
- The design and implementation approach
- The expected impact
- Limitations and future improvements

---

# Required Materials

Depending on the type of solution, teams should provide relevant materials.

## Solution Documentation

Include:

- Problem overview
- Proposed approach
- Technical details
- Design decisions
- Expected outcomes

---

## Prototype or Demonstration

Teams may provide:

- Software prototype
- Hardware prototype
- CAD models
- Simulations
- Data analysis results
- User interface designs

The demonstration should clearly show how the proposed solution works.

---

## Source Code

For software-based solutions, include:

- Source code
- Installation instructions
- Dependencies
- Usage instructions


---

# Presentation Requirements

Teams will present their solution to judges.

The presentation should include:

## Problem Understanding

Explain:

- The problem
- Why it matters
- Who is affected

## Proposed Solution

Explain:

- How the solution works
- Why it addresses the challenge
- Key features

## Implementation

Explain:

- Technical approach
- Tools and technologies used
- Development process

## Demonstration

Depending on the project, include:

- Live demo
- Prototype demonstration
- Videos
- Animations
- Simulation results

## Impact

Explain:

- Expected benefits
- Potential users
- Future improvements

---

# Technical Requirements

Submissions should:

- Include clear documentation
- Provide setup instructions if applicable
- Identify external tools, APIs, or datasets used
- Reference external resources properly

Avoid including:

- Unnecessary files
- Private information
- Large generated files

---

# Accessibility Requirements

All submission materials should follow accessibility guidelines.

Teams should ensure:

- Documents use proper heading hierarchy
- Images include alternative text
- Videos include captions
- Presentations use readable font sizes
- Colours have sufficient contrast
- Hyperlinks use descriptive text

See [Accessibility Guidelines](../accessibility.md) for more information.

---

# Submission Checklist

Before submitting, confirm:

- [ ] Solution addresses the challenge objectives
- [ ] Documentation is complete
- [ ] Prototype or demonstration is included
- [ ] Presentation materials are prepared
- [ ] Required resources are referenced
- [ ] Accessibility requirements are followed
